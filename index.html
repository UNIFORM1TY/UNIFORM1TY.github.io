Product model

One OS. Separate worlds.

Uniformity does not merge every project into one product. Each surface owns its own domain truth, and the boundary stays explicit even when the experience feels seamless.

Uniformitythe OS
Owns identity, canonical object and state, permissions, events, orchestration and role/context projections. Must not own instrument semantics or advisory reasoning.
LOGARHYTHM / SUBANGELone instrument world
Public and cultural identity plus instrument archive, diagnostics, repair workflow and service-history depth. Must not own cross-domain OS truth.
JUNO-106reference object

Fridge Brainadvisory service
May retrieve, interpret, rank, cite and propose one next action. Must never mutate canonical state, accept actions, or write history.
RESELL · UCMRdomain adapters
Their own domain semantics and workflows, composed through the same runtime contract. Must not own instrument-domain truth.
Hermes + Nousresearch / operator
The research and governed-execution cross-reference. Not product truth.
Shared runtime grammar

Eight stages. Every domain.

The same pipeline governs any object, whichever world owns it. Intelligence advises; it never mutates.

01 · Object

Canonical identity

One stable object_id that every projection resolves to.

02 · State

Operational state

The current condition of that object, versioned — never overwritten.

03 · Signal

Observed event

An event or condition detected against the object.

04 · Evidence

Governed material

Revision-aware, permission-scoped, provenance-bearing.

05 · Intelligence

Advisory only

Ranked hypotheses, confidence, contradictions — never canonical mutation.

06 · Action

Domain-owned work

Proposed, accepted, started, completed — owned by the workshop layer.

07 · Verification

Result + new evidence

Recorded at completion. Staging is not verification.

08 · History

Immutable events

The object can be reconstructed and audited from its history alone.

Architecture

Governed evidence in. Advisory assessment out.

Uniformity filters evidence before it crosses the Fridge Brain boundary. The service validates defensively and returns interpretation — never authority.
